## Adding New Assets

When pulling in a new pack:
1. Extract under `assets/models/<category>/<pack_name>/`
2. Verify license: must be CC0 / CC-BY / commercial-OK
3. Add an entry to this file with path, author, source URL, license
4. If CC-BY, keep attribution requirement explicit
